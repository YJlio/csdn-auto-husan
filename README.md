# CSDN 自动互三工具

一个用于 CSDN 文章页面的油猴用户脚本。点击页面悬浮按钮或按空格，可依次执行评论、点赞、收藏和关注。脚本会根据文章标题生成评论，并通过本地记录控制执行频率和避免重复评论。

## 安装

1. 在浏览器中安装并启用 Tampermonkey（油猴）扩展。
2. 点击 [安装 CSDN 自动互三工具](https://raw.githubusercontent.com/YJlio/csdn-auto-husan/main/csdn-auto-husan.user.js)，在油猴页面确认安装。
3. 打开 CSDN 文章详情页，点击悬浮按钮或按空格键执行。

## 配置

在脚本开头的 `CONFIG` 中，可以设置是否自动提交评论、点赞、收藏、关注以及是否启用空格快捷键。默认开启这些选项，限速配置为 60 秒内最多执行 3 次。

执行结果以页面显示及实际状态为准；部分操作可能显示“待核实”。

当前脚本版本：3.5.0。
